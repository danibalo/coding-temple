## Employee Directory Joins

Build a multi-table database and write JOIN queries to answer business questions.

### What I Implemented

- Created an in-memory SQLite database
- Designed `departments`, `employees`, and `projects` tables
- Added primary and foreign key relationships
- Populated the database with sample data
- Used `INNER JOIN` and `LEFT JOIN` queries
- Identified employees without projects
- Joined three tables to connect projects, employees, and departments

This project strengthened my ability to design relational databases and retrieve related data using SQL.
