def all_pairs(data):
    pairs = []
    for i in range(len(data)):
    	for j in range(len(data)):
	   pairs.append((data[i], data[j]))
    return pairs
Answer: Its Big O time complexity is O(n^2), there is n operation for every n input

def mystery(n):
   count = 0
   while n > 1:
      n = n // 2
      count += 1
   return count

Answer: Its Big O time complexity is O(logn). Each steps cut the operation in half.

def process(data):
	total = sum(data) #O(n)
	sorted_data = sorted(data) #O(nlogn)
	first = data[0] #O(1)
	return total, sorted_data, first

Answer: Time complexity is O(nlogn) as it is the dominant term among all complexities.
